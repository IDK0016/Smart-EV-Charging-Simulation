Smart EV Charging Simulation System (Prototype)

This project demonstrates a full user flow for EV charging management including session start, live tracking, billing, and admin monitoring.

The current version is a frontend MVP deployed via GitHub Pages. 
Backend services using Node.js, Express, and MongoDB have been designed and are under integration.

Planned integrations:
- JWT authentication
- Real-time session tracking
- Payment gateway (UPI/Razorpay)
- SMS/email notifications

This prototype showcases system design and user experience for real-world deployment.
